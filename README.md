# Retail Sales Analysis Dashboard Using Microsoft Excel

## Project Overview

This project focuses on analyzing retail sales data from four major retailers: Walmart, Walgreens, Target, and Costco.

I used Microsoft Excel to clean, transform, analyze, and visualize the data. The main goal was to understand sales performance, identify top-performing retailers and beverage brands, and present useful business insights through an interactive dashboard.

## Project Objectives
Analyze sales performance across different retailers.
Identify the best-selling beverage brands.
Understand monthly sales trends.
Compare retailer performance by beverage brand.
Analyze sales performance across different regions.
Build an interactive Excel dashboard for business reporting.

## Tools & Technologies
Microsoft Excel
Power Query – Data cleaning and transformation
PivotTables – Data analysis and summarization
PivotCharts – Data visualization
Slicers – Interactive filtering
Excel Formulas – KPI calculations

## What I Did
Total sales by retailer.
Total sales and units sold by beverage brand.
Sales comparison between retailers and beverage brands.
Monthly sales performance.
Regional sales performance.

Created the following key performance indicators:

Total Revenue

## Interactive Dashboard Development
Designed an Excel dashboard using PivotCharts and Slicers.
